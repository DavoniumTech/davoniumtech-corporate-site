# V60 Design Direction — Davonium Precision Experience

V60 continues the Davonium Signal Architecture system. Dark graphite remains the default, with a fully separate porcelain light environment. Both themes share the same layout, content, navigation, and interaction behaviour, but use separate surface, text, shadow, and atmosphere tokens.

The desktop homepage is composed around a balanced text/character split with a full-width audience strip below. The header is kept above the floating assistant/contact controls. Page headings use Cormorant Garamond as an editorial display face; Manrope remains the reading face so long-form documentation and product details stay clear. Button visual language is intentionally inherited from the existing release.

The starfield is a persistent page-level atmosphere, not a section background. Sections remain transparent while meaningful content is contained in individually readable cards. Status indicators have gentle floating and glow motion. The DVNM Bot remains the existing character; browser speech word-boundary events animate a mouth overlay and active voice state illuminates the chest overlay. This is visual synchronisation to browser speech events, not a generated phoneme-perfect facial animation.
