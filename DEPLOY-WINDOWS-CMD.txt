DAVONIUM TECHNOLOGIES — COMPANY RELEASE DEPLOYMENT GUIDE
Updated: 15 October 2026

READ FIRST
This release is designed for https://www.davoniumtech.com/. The public guides focus on products, visitor outcomes, support, and verified company practices instead of advertising internal implementation choices. Browser-delivered resources can still be inspected; do not store secrets in public files. Keep the source repository private if source-history visibility matters, after verifying the hosting integration retains access.

1. EXTRACT THE ZIP
Run these commands from Windows CMD after saving the ZIP in Downloads:

cd /d "%USERPROFILE%\Downloads"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Expand-Archive -LiteralPath '%USERPROFILE%\Downloads\davonium-technologies-public-company-release.zip' -DestinationPath '%USERPROFILE%\Downloads\davonium-technologies-public-company-release' -Force"
dir "%USERPROFILE%\Downloads\davonium-technologies-public-company-release\index.html"

2. UPDATE THE EXISTING COMPANY REPOSITORY
cd /d "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy"
git remote -v
git status
git fetch origin
git switch main
git pull --ff-only origin main

Confirm that origin is https://github.com/DavoniumTech/davoniumtech-corporate-site.git. Stop if the working tree contains changes you need to preserve. Create a backup branch with a unique name before copying:

git branch backup-before-public-company-release-20261015-2045
git push origin backup-before-public-company-release-20261015-2045

If that branch name already exists, choose a different name.

3. COPY AND REVIEW
robocopy "%USERPROFILE%\Downloads\davonium-technologies-public-company-release" "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy" /E /XD .git
echo %ERRORLEVEL%

Robocopy exit codes 0–7 usually mean the copy completed; 8 or higher means failure. Never use /MIR for this operation.

git status
git add .
git diff --cached --stat

Review the files, then commit and push:

git commit -m "Improve Davonium company experience and public discovery"
git push origin main

A successful push does not prove that production deployed. Check the latest Cloudflare build and open the live pages on a phone and desktop.

4. CANONICAL DOMAIN
The preferred public address is https://www.davoniumtech.com/. The Search Console screenshot shows the www homepage request was accepted, while the bare-domain inspection reported issues. In Cloudflare, open the davoniumtech.com zone → Rules → Redirect Rules and create a 301 wildcard redirect:
Request URL: http*://davoniumtech.com/*
Target URL: https://www.davoniumtech.com/${2}
Status code: 301
Preserve query string: enabled

Test the bare-domain homepage and a nested path. Both should redirect once to the matching www URL. Do not create a rule that redirects www back to itself. See https://developers.cloudflare.com/rules/url-forwarding/examples/redirect-domain/.

5. SEARCH DISCOVERY
Google Search Console accepted the www homepage into a priority crawl queue. Bing accepted the sitemap submission with no sitemap errors, but the screenshot showed zero URLs discovered at that initial moment. These are positive initial steps, not a guarantee that every page will be indexed within a week. Submit https://www.davoniumtech.com/sitemap.xml once, inspect the www homepage and important guide URLs, and check the processing report again after the services have had time to crawl. Google says crawling and indexing timing cannot be guaranteed: https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl.

Bing IndexNow notification (optional, run in PowerShell after deploy, not CMD):
$body = @{ host = "www.davoniumtech.com"; key = "cdc1781eecd88b39bcc5f4ad15872ca7"; keyLocation = "https://www.davoniumtech.com/cdc1781eecd88b39bcc5f4ad15872ca7.txt"; urlList = @("https://www.davoniumtech.com/", "https://www.davoniumtech.com/products", "https://www.davoniumtech.com/docs/", "https://www.davoniumtech.com/contact", "https://www.davoniumtech.com/docs/guides/seo-discovery", "https://www.davoniumtech.com/docs/guides/ai-discovery") } | ConvertTo-Json -Depth 4
Invoke-RestMethod -Method Post -Uri "https://api.indexnow.org/indexnow" -ContentType "application/json; charset=utf-8" -Body $body

IndexNow is a discovery notification, not a guarantee of indexing; it does not replace Google Search Console.

6. SECURITY AND VISIBILITY
The _headers file adds browser security headers for static page responses. After deployment, verify the live headers and check browser console for any Content-Security-Policy violations. The site has no server-side account or payment system by virtue of being a company information site; browser-side checks cannot protect secrets. Never place passwords, private API keys, customer records, or recovery codes in public files.

robots.txt allows OAI-SearchBot for ChatGPT Search discovery while expressing a separate disallow preference for GPTBot training crawl. Other crawlers have their own rules. Crawler instructions are not access control. To hide the GitHub source repository from public browsing, change its visibility to Private only after confirming the Cloudflare Git integration is authorised to read the private repository. Browser-delivered files will remain inspectable regardless.

7. AFTER DEPLOYMENT
Check the home page, products, services, contact, documentation index, representative guides, WhatsApp action, system theme, installation help, direct links, missing-page response, and offline reopening after the required pages have been visited online. Verify sitemap URLs are canonical and that draft policy pages remain excluded from indexing until reviewed.
