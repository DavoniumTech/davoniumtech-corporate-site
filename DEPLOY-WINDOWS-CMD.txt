DAVONIUM TECHNOLOGIES — FAST LOADING & APP INSTALL UPDATE

This release makes first installation lighter, shows a visible Install app link on every page, repeats the optional invitation no more than once every seven days after dismissal, and adds rounded normal app icons plus separate maskable icons.

1. Download this ZIP into Downloads and extract it with CMD:

cd /d "%USERPROFILE%\Downloads"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Expand-Archive -LiteralPath '%USERPROFILE%\Downloads\davonium-technologies-fast-install-refresh.zip' -DestinationPath '%USERPROFILE%\Downloads\davonium-technologies-fast-install-refresh' -Force"

2. Go to the existing company repository:

cd /d "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy"
git status
git remote -v

Confirm the remote is https://github.com/DavoniumTech/davoniumtech-corporate-site.git. If `git status` shows local changes you want to keep, stop and resolve them first.

3. Update main:

git fetch origin
git switch main
git pull --ff-only origin main

4. Create a safety backup:

git branch backup-before-fast-install-refresh-20261015
git push origin backup-before-fast-install-refresh-20261015

If that backup branch already exists, use a different backup name before continuing.

5. Copy the release files:

robocopy "%USERPROFILE%\Downloads\davonium-technologies-fast-install-refresh" "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy" /E /XD .git

echo %ERRORLEVEL%

Robocopy codes 0–7 normally indicate success. If the code is 8 or higher, stop and review the error. Do NOT use /MIR.

6. Review, commit and push:

git status
git add .
git diff --cached --stat
git commit -m "Improve loading and PWA install experience"
git push origin main

If Git says there is nothing to commit, inspect `git status` instead of repeating the commit. If push is rejected because main moved on GitHub, stop and share the error before retrying.

VERIFY AFTER DEPLOYMENT
- Open the website normally and in a private browser window; look for the Install app link in the top navigation.
- The optional invitation appears on the homepage and Products page if it was not dismissed within the previous seven days and the website is not already running as an installed app.
- If the browser has no native install prompt, the button explains device-specific manual steps. Some browsers do not expose a JavaScript prompt.
- Test the home screen icon on Android/iOS/desktop. The `any` icons have rounded transparent corners; the separate `maskable` icons let launchers apply their own preferred icon shape. A launcher may override icon styling.
- For offline testing, visit pages online once, then test them offline. Pages are cached when visited; the service worker no longer downloads every documentation page during first installation.
