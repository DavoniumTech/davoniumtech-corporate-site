DAVONIUM TECHNOLOGIES — COMPANY DOCUMENTATION RELEASE

This release rewrites our public documentation in the company voice, removes repeated template copy, adds a public AI-discovery guide, expands llms-full.txt, and updates robots.txt and sitemap.xml.

1. Download this ZIP to Downloads and extract it in CMD:

cd /d "%USERPROFILE%\Downloads"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Expand-Archive -LiteralPath '%USERPROFILE%\Downloads\davonium-technologies-company-voice-release.zip' -DestinationPath '%USERPROFILE%\Downloads\davonium-technologies-company-voice-release' -Force"
dir "%USERPROFILE%\Downloads\davonium-technologies-company-voice-release\index.html"

2. Open the existing company repository. We do not need a second clone:

cd /d "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy"
git remote -v
git status

Confirm the remote is https://github.com/DavoniumTech/davoniumtech-corporate-site.git. If the working tree contains changes that need to be kept, stop and preserve them before copying.

3. Update main and create a backup branch. If this backup name exists already, choose a new name:

git fetch origin
git switch main
git pull --ff-only origin main
git branch backup-before-company-voice-refresh-20261015
git push origin backup-before-company-voice-refresh-20261015

4. Copy the release into the repository (do not use /MIR):

robocopy "%USERPROFILE%\Downloads\davonium-technologies-company-voice-release" "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy" /E /XD .git
echo %ERRORLEVEL%

Robocopy codes 0–7 generally indicate success. If the result is 8 or higher, stop and inspect the error.

5. Review and publish:

git status
git add .
git diff --cached --stat
git commit -m "Rewrite public docs in Davonium company voice"
git push origin main

If there is nothing to commit, inspect git status rather than repeating the commit. If Git rejects the push because main advanced, stop and share the full error; do not force-push.

6. After Cloudflare reports a successful deployment, test these URLs:
- https://www.davoniumtech.com/
- https://www.davoniumtech.com/docs/
- https://www.davoniumtech.com/docs/guides/seo-discovery
- https://www.davoniumtech.com/docs/guides/ai-discovery
- https://www.davoniumtech.com/llms.txt
- https://www.davoniumtech.com/llms-full.txt
- https://www.davoniumtech.com/robots.txt
- https://www.davoniumtech.com/sitemap.xml

7. In Google Search Console, verify domain ownership, submit the sitemap, and inspect priority URLs. The sitemap and crawler policy support discovery but do not guarantee indexing or rankings. Check Cloudflare security rules if legitimate crawlers receive blocked responses.
