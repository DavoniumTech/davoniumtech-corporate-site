DAVONIUM TECHNOLOGIES — WINDOWS CMD DEPLOYMENT

1. Extract the ZIP to: %USERPROFILE%\Downloads\davonium-technologies-final-website
2. Update the first path below if your company-site clone has another folder name.
3. Ensure the Git remote is the company website repo, not a product repo.

cd /d "%USERPROFILE%\Downloads\davoniumtech-corporate-site"
git status
git remote -v
git switch -c website-final-refresh-2026
robocopy "%USERPROFILE%\Downloads\davonium-technologies-final-website" "." /E /XD .git
git status
git add .
git diff --cached --stat
git commit -m "Refresh Davonium Technologies company website"
git push -u origin website-final-refresh-2026

Stop if the repository remote is wrong or the working tree contains changes you do not understand. Never use robocopy /MIR. Robocopy exit codes 8 or higher indicate an error. Review the preview and merge only into the correct Pages production branch.
