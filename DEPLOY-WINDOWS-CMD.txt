DAVONIUM TECHNOLOGIES — SYSTEM THEME + READY2GO ICON UPDATE

This is a static HTML/CSS/JavaScript website. No Node.js, npm, React, Vite, or build command is required for editing the files.

1) Extract the ZIP using CMD (assuming this ZIP is in Downloads):

cd /d "%USERPROFILE%\Downloads"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Expand-Archive -LiteralPath '%USERPROFILE%\Downloads\davonium-technologies-system-theme-refresh.zip' -DestinationPath '%USERPROFILE%\Downloads\davonium-technologies-system-theme-refresh' -Force"

2) Enter your existing company-site repository (do not clone another copy):

cd /d "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy"
git remote -v
git status

The remote must be https://github.com/DavoniumTech/davoniumtech-corporate-site.git. If git status shows local changes you have not committed, stop and review them before copying.

3) Refresh main and create a backup reference before deploying:

git fetch origin
git switch main
git pull --ff-only origin main
git branch backup-before-system-theme-refresh-20261015
git push origin backup-before-system-theme-refresh-20261015

4) Copy this package into the repository. Do not use /MIR:

robocopy "%USERPROFILE%\Downloads\davonium-technologies-system-theme-refresh" "%USERPROFILE%\Downloads\davoniumtech-corporate-site-deploy" /E /XD .git
echo %ERRORLEVEL%

Robocopy exit codes 0–7 normally indicate the copy completed without a fatal error. If the code is 8 or higher, stop and inspect the error.

5) Review, commit, and push the changes directly to main:

git status
git add .
git diff --cached --stat
git commit -m "Use system appearance and official Ready2Go icon"
git push origin main

If Git says there is nothing to commit, do not repeat the command; check whether the files were already copied/committed. If push is rejected because main advanced remotely, run git fetch origin and git pull --ff-only origin main, then review any conflict before trying again. Never force-push.

6) Verify the live website after the Cloudflare deployment completes:
- Open https://www.davoniumtech.com/ in a browser set to light appearance and then dark appearance.
- In a private/incognito session with no saved theme choice, the site should initially follow the browser/operating-system appearance.
- Change OS appearance while the site is open; when the saved theme mode is System, the page should change with it.
- Use the theme button to test manual appearance and cycle back to System as indicated by its accessible label/title.
- Confirm the actual R2G logo appears in the home page, Products page, Our Work cards, documentation listing, and Ready2Go product guide.
- Test the site install flow as before. The company website's own install icon remains the Davonium brand, not the Ready2Go product icon.

The Cloudflare production deploy command should be `npx wrangler deploy`, with root directory `/` and no build command for this static site. Preview deployment should be configured separately according to the Cloudflare dashboard's Worker Previews settings. Verify the deployment logs; a successful Git push does not by itself guarantee deployment success.
