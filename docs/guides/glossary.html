Web and product glossary

Plain-language meanings for the technical terms we use in our website, product pages, and documentation.

Website and hosting terms

A static website serves prebuilt HTML, CSS, JavaScript, and assets. A domain is the human-readable address; DNS points that domain towards the relevant hosting service.

We use Cloudflare Workers Static Assets to publish our company website and configure clean URLs through Wrangler.

  • Canonical URL: the preferred address we publish for a page.
  • 404: the HTTP status used when a requested page or asset is not found.

PWA and offline terms

A Progressive Web App (PWA) is a website that can offer app-like installation and selected offline behaviour when a browser supports those features.

The web manifest describes the app identity and icons, while a service worker manages selected caching and offline responses.

  • Service worker: a browser script that can intercept requests and manage caches.
  • Maskable icon: an icon designed to be safely cropped to a device launcher’s shape.

Search terms

Crawling is when a bot requests pages; indexing is the search system’s decision to store and potentially show a page; ranking is how results are ordered for a particular query.

A sitemap and robots policy help explain our website, but neither guarantees indexing or a particular position.

  • Structured data: machine-readable information that describes visible page content.
  • LLM: a large language model; llms.txt is a proposed text convention for describing public resources to compatible tools.

Security and privacy terms

Authentication checks who is signing in; authorization checks what that identity may do. HTTPS encrypts traffic between the browser and site, but it does not by itself make every application secure.

We avoid calling a product “completely secure” and explain specific protections only when we have verified them.

  • Data minimisation: collecting only what a defined purpose requires.
  • Retention: the period for which information is kept before deletion or review.

Using these terms

We use these meanings consistently across our public pages. Where an implementation detail is browser-dependent, we describe the limitation rather than defining it as a guarantee.
