Cookies and browser storage guide

What our website stores in the browser for theme preference, installation reminders, and offline access.

What our website stores

Our site uses browser storage for small preference values such as the selected theme, whether the app-install invitation was dismissed, and whether installation was observed in the current browser.

These values help the interface remember a choice. They are not a user account and do not create a server-side profile.

  • Theme preference can be set to follow the operating system or a chosen light/dark mode.
  • The invitation and installation flags control the frequency of the install reminder.

Offline cache

Our service worker stores selected HTML pages and assets in the browser’s Cache Storage so previously visited pages can sometimes reopen without a network connection.

Browser cache data remains on that device and may be cleared by the browser, device owner, storage cleanup, or a new service-worker release.

  • Essential files are cached first; other pages are cached when they load successfully.
  • External product sites, mail handlers, and uncached pages still need a connection.

Cookies and analytics

Our public website does not require a login cookie to read its pages. We do not claim that the local theme preference is a cookie; it is stored with the browser storage API.

If we introduce an analytics provider, login service, advertising tool, or other technology that changes data collection, we will review the privacy and cookie information before release.

  • We avoid putting personal information or secret values into browser storage.
  • We keep privacy descriptions aligned with actual scripts and network requests.

Clearing local data

You can clear site data in your browser settings. Doing so can reset the theme choice, dismissals, and offline cache.

Our privacy and storage policy pages are still draft policy text and have not been presented as qualified legal review.

  • We explain how a reset affects the experience.
  • We review these statements when storage behaviour changes.

Storage choices

We keep browser storage limited to interface preferences and the files needed for the installable website experience. We update this guide if our implementation changes.
