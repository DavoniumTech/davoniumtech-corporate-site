DVNM Bot visitor guide

How the Davonium Technologies animated visitor guide works, including questions, voice controls, motion, accessibility, privacy, and current limits.

What DVNM Bot is

DVNM Bot is the animated visitor guide for the Davonium Technologies website. It is designed to help a first-time visitor find company information, products, services, the Demo Studio, public documentation, and contact details without hunting through every page.

The current version uses the browser’s built-in Speech Synthesis API for voice output. A visitor chooses a question first, reads the displayed answer, and presses the voice button when they want to hear it. A first-visit welcome banner appears visually by default, but it never plays audio automatically. Visitors can skip it, enter an optional first name for the current visit, or explicitly press Hear introduction.

How to use the guide

  1. On a first visit, the welcome banner introduces DVNM Bot automatically as a visual message.
  2. Use Skip and explore the website at any time to dismiss the welcome and continue directly.
  3. Enter a first name only if you would like a personalised greeting. The name remains in page memory and is not submitted to a server.
  4. Select Meet DVNM Bot to open the question panel or Hear introduction to request spoken output.
  5. Choose a subject: company, products, services, sample demonstrations, documentation/offline use, or contact.
  6. Each subject has a longer written answer and a relevant page link, so visitors can read, listen, or navigate.
  7. Open Voice and speaking settings to select an installed device voice, lower speech volume, or change the speaking pace.
  8. Press Stop voice whenever you want speech to end; the visible answer and link remain available.
  9. Use Escape to close the bot panel. The first-visit welcome is shown once per browser tab session, not on every internal navigation.
  10. Speech output starts only after a visitor presses a voice control. The welcome banner itself never autoplays sound.

The character has glowing eyes, antenna beacon lighting, a luminous DVNM chest badge, mechanical panel details, a small wave, gentle floating motion, a hologram-style base, and a mouth animation that activates during spoken output. Speech events vary by browser; the mouth is activity-synchronised approximately and is not phoneme-perfect lip-sync.

How the robot expresses speech

DVNM Bot uses a branded full-body robot illustration with a confident upright stance and the illuminated DVNM chest mark. Animated eye overlays give the character open, illuminated eyes with natural blink intervals. When spoken output starts, the mouth animation opens and closes and the body makes a restrained speaking movement; when speech ends, the mouth returns to its resting smile.

The visual animation is synchronized to the browser's speech-active events, not to individual phonemes. A visitor can stop speech at any time. Reduced-motion preferences are respected, and the written answer and navigation links remain available if the device cannot speak.

Accessibility, user control, and privacy

Motion is reduced when the visitor’s operating system requests reduced motion. Controls are real buttons with accessible labels, written answers remain available if speech is unsupported, and Escape closes the assistant panel. Voice begins only after the user acts on a voice control. A soft default volume and slower pace are selected, and visitors may change the voice if their device exposes choices.

Answers and navigation destinations are defined in the website code; the current guide is not a generative AI chatbot and does not submit visitor questions to a model or external service. The speech voice is provided by the browser/device and may differ by operating system, language packs, and accessibility settings.

Current limits and future direction

  • It answers a curated set of common site-navigation questions rather than arbitrary questions.
  • Available voices, volume handling, pronunciation, and voice names are browser- and device-dependent; no paid voice service or external audio provider is required.
  • It does not collect user accounts, contact forms, or personal records.
  • Future expansions should add reviewed answers, clear status messages, accessibility checks, device test coverage, and product-approved content before any remote AI service is introduced.

The assistant is one part of the company website experience, not a substitute for written documentation or direct support.

Transparent floating launch control

We keep one transparent DVNM Bot launch control fixed near the lower-right edge of each page. The robot silhouette has no square or rectangular card behind it, remains reachable by keyboard, and adjusts to mobile safe areas and short landscape screens. Opening the guide exposes the visitor's existing questions and controls.

Speaking expression and chest glow

When a visitor chooses to hear an answer, our visual state opens and animates the robot mouth, adds a stronger glow around the DVNM chest emblem, and moves the robot gently. This animation follows the browser speech engine's active state rather than individual phonemes. The Cancel Speech control immediately ends playback when the browser supports speech synthesis.
