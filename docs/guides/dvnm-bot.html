DVNM Bot visitor guide

How the Davonium Technologies animated visitor guide works, including questions, voice controls, motion, accessibility, privacy, and current limits.

What DVNM Bot is

DVNM Bot is the animated visitor guide for the Davonium Technologies website. It is designed to help a first-time visitor find company information, products, services, the Demo Studio, public documentation, and contact details without hunting through every page.

The current version uses the browser’s built-in Speech Synthesis API for voice output. A visitor chooses a question first, reads the displayed answer, and presses the voice button when they want to hear it. The website does not autoplay a spoken welcome.

How to use the guide

  1. Open Ask DVNM Bot from the floating assistant on a company page.
  2. Choose a topic such as products, services, website demos, documentation, or contact.
  3. Read the written response and use the linked page when ready.
  4. Press Hear this answer to request spoken output, or Stop voice to interrupt it.

The character has blinking eyes, a small wave, gentle floating motion, and a mouth animation that activates during spoken output. Speech events vary by browser; the mouth is activity-synchronised approximately and is not phoneme-perfect lip-sync.

Accessibility, user control, and privacy

Motion is reduced when the visitor’s operating system requests reduced motion. Controls are real buttons with accessible labels, written answers remain available if speech is unsupported, and Escape closes the assistant panel. Voice begins only after the user acts on a voice control.

Answers and navigation destinations are defined in the website code; the current guide is not a generative AI chatbot and does not submit visitor questions to a model or external service. The speech voice is provided by the browser/device and may differ by operating system, language packs, and accessibility settings.

Current limits and future direction

  • It answers a curated set of common site-navigation questions rather than arbitrary questions.
  • Available voices and pronunciation are browser-dependent; no paid voice service or external audio provider is required.
  • It does not collect user accounts, contact forms, or personal records.
  • Future expansions should add reviewed answers, clear status messages, accessibility checks, and tests before any remote AI service is introduced.

The assistant is one part of the company website experience, not a substitute for written documentation or direct support.
