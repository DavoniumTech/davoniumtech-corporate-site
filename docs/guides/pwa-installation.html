Installing the Davonium Technologies website

How the Davonium Technologies website can be installed through compatible browsers and what its install prompt can and cannot do.

What installation adds

On a supported device, you can add Davonium Technologies to your home screen or apps list and open it in an app-like window. The shortcut makes it quicker to return to company information, products, public guides, and support.

Android

Open the website in a supported browser and use the visible Install app option when the browser offers it. If the browser does not display an installation prompt, open its menu and look for “Install app” or “Add to Home screen”. The label varies by browser and device.

iPhone and iPad

Open the website in Safari, tap Share, choose “Add to Home Screen”, and confirm. Browser-managed prompts vary across iOS versions, so the Share menu remains a useful fallback.

Desktop

In a compatible browser, look for the install symbol in the address bar or the browser menu. If no install option appears, continue using the website normally or follow the browser's own help.

What installation does not mean

This adds a website shortcut; it does not download a separate Android APK. The browser and operating system control the installation and the shape of the app icon. Selected pages may reopen offline after they have been cached, but the first visit and external product links need a connection.
