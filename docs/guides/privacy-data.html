Data handling and privacy principles

Data minimisation, transparency, access control, and retention basics.

Purpose. Data minimisation, transparency, access control, and retention basics. Use this guide as practical information and verify details against the deployed product and any applicable agreement.

Overview and purpose

Collect personal data only for a defined and proportionate purpose. The organisation should be able to explain why a field is requested, how it is used, and when it is no longer needed.

For this area, the team should make the intended behaviour explicit, keep the implementation proportionate to the need, and record any constraint that could affect a user. Where a service relies on a browser feature or external provider, describe that dependency instead of implying universal support.

  • Identify the person, task, and expected result relevant to data handling and privacy principles.
  • State requirements and limitations in language a non-specialist can follow.
  • Test the common path, an error path, and the recovery route before release.
