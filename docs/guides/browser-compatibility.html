Browser compatibility guide

How we make the public website usable across modern mobile and desktop browsers while handling optional features safely.

A dependable experience across devices

We design our company pages so people can read important information and follow direct links using current mainstream browsers on phones, tablets, and computers. Visitors should not need a special extension to learn about the company, review product status, or find contact details.

Progressive enhancement

The page itself is the foundation. Optional features such as appearance controls, documentation filtering, installation help, offline reopening, and scroll reveals enhance the experience but should not replace the underlying content or links.

Native installation prompts depend on the browser and device. When the browser does not offer a prompt, we provide manual installation instructions rather than pretending the native flow is available.

Responsive behaviour

Layouts adapt to narrow phones and wide displays. We avoid making the primary action available only on hover, preserve readable line lengths, and keep the mobile menu easy to open and close. We check touch targets, zoom, orientation changes, keyboard focus, and reduced-motion preferences.

When something differs

Browsers vary in installation prompts, offline support, and some visual details. When a feature depends on a browser capability, the experience provides a useful fallback. We record limitations rather than describing every browser as identical.

Report a reproducible issue through our contact page.
