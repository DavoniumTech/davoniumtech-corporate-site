Documentation navigation and search

How our documentation remains reachable through direct links while the search tool helps visitors narrow the list.

Direct links come first

Our documentation index contains ordinary HTML links for every guide. A visitor or crawler can open a guide directly without typing in the search field or waiting for a JavaScript event.

The search field is a convenience for filtering a visible list, not a hidden routing system.

  • Each guide has its own canonical URL and title.
  • The guide links remain in the HTML before filtering starts.

How our local search works

The browser matches the visitor’s query against the guide title, summary, category, and page-card text. Matching cards remain visible; nonmatching groups are hidden only for that browser view.

This search is local to the documentation page. It does not send the query to a server or search all the public internet.

  • Type a short topic or product name to narrow the list.
  • Use Clear to restore every guide and the published guide count.

Accessibility and no-JavaScript behaviour

We label the search input, provide an announced result count, and keep all guide links present as normal anchors. If JavaScript is unavailable, the full guide list remains browseable.

Interactive filtering is not a replacement for crawlable URLs or descriptive text.

  • We keep the empty result message actionable.
  • We test the filter and Clear button after changes to the card markup.

Search visibility

We link guides from a central documentation landing page and relevant related-guide sections. Metadata, sitemap entries, and the published robots policy provide additional discovery signals.

We cannot force an external search engine or AI system to crawl, index, rank, or cite any page.

  • We monitor important routes through available webmaster tools.
  • We keep public summaries specific enough to describe the guide accurately.

Finding a guide

We keep each guide linked in the documentation index so search is an extra convenience, not the only way to reach the content.
