# Public release checklist

- [ ] Confirm support@davoniumtech.com forwarding/mailbox works; fallback Gmail is correct.
- [ ] Confirm phone and WhatsApp numbers and link tests.
- [ ] Test every page on mobile and desktop.
- [ ] Test keyboard nav, Escape-to-close mobile menu, focus visibility, reduced motion and theme toggle.
- [ ] Test PWA manifest/icon installation on supported browsers.
- [ ] Test offline cache after first successful visit and after a later update.
- [ ] Validate title/meta/canonical tags and all internal links.
- [ ] Confirm `robots.txt`, `sitemap.xml`, `llms.txt` and `.well-known/security.txt` use the final canonical domain.
- [ ] Review privacy/terms/legal statement accuracy.
- [ ] Confirm product status language and live URLs.
- [ ] Configure Cloudflare Pages custom domain only after pages.dev deployment works.
- [ ] Preserve email MX/TXT records, Ready2Go subdomain, Marvel Chat subdomain and other existing DNS records.
- [ ] Verify property in Google Search Console and submit sitemap.
- [ ] Remember that search indexing and ranking cannot be guaranteed.
