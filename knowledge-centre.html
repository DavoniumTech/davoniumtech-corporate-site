Digital business & customer experience

22 terms
Digital presence
The collection of online places where people can discover, understand and contact an organisation.
Brand identity
The visual and verbal elements that make an organisation recognisable and consistent.
Value proposition
A clear explanation of who a service helps, what it does and why it matters.
Target audience
The people or organisations a product or service is intended to help.
Customer journey
The steps a person takes from first discovery through action and follow-up.
Touchpoint
Any interaction where a person encounters a brand, service or product.
Conversion
A meaningful action such as an enquiry, booking, purchase or registration.
Call to action (CTA)
A clear prompt that tells a visitor what useful step to take next.
Lead
A person or organisation that has expressed interest in a service or product.
Lead qualification
A process for understanding whether an enquiry matches the service, timing and budget.
Customer relationship management (CRM)
A system for recording and organising customer contacts, conversations and follow-up tasks.
Sales funnel
A simplified view of the stages people pass through before becoming customers.
Customer retention
Work that encourages existing customers to continue using or buying a service.
Customer onboarding
The steps that help a new customer understand and start using a product.
Service scope
The agreed activities, deliverables, boundaries and exclusions for a client engagement.
Deliverable
A defined item of work that is handed over or made available to a customer.
Handoff
The transfer of files, access, guidance and responsibilities after delivery.
Maintenance
Ongoing work to keep a website or software useful, secure and reliable.
Business process
A repeatable set of activities that helps an organisation complete a task.
Operational workflow
A connected sequence of tasks, people, decisions and information used to run work.
Service-level agreement (SLA)
A written agreement describing service availability, response targets and responsibilities.
Return on investment (ROI)
A comparison between the value produced and the resources spent on an activity.
02 / 10

Web & browser foundations

22 terms
HyperText Markup Language (HTML)
The standard markup used to structure content and meaning on web pages.
Cascading Style Sheets (CSS)
The language that controls how web content is presented across screen sizes.
JavaScript
A programming language commonly used to add behaviour and interactivity to websites.
Static website
A site served as prepared files without generating each page from live user data.
Dynamic website
A site that can generate or update content using application logic or stored data.
Multi-page application (MPA)
A website where navigation typically loads separate document pages for different routes.
Single-page application (SPA)
A web application that updates views in the browser without full document navigation.
Content management system (CMS)
Software that helps authorised people create, edit and publish website content.
Headless CMS
A content system that provides content through an API separately from the presentation layer.
Responsive design
An approach that adapts layout and controls to different screen sizes and orientations.
Mobile-first design
A design approach that starts with small screens and expands for larger devices.
Semantic HTML
HTML elements chosen for the meaning and role of their content.
Document Object Model (DOM)
The browser's structured representation of a document that scripts can inspect and update.
Browser rendering
The process of turning HTML, CSS and assets into the visible page.
URL
The address used to locate a page or resource on the internet.
Slug
The readable part of a URL used to identify a page or content item.
Canonical page
The preferred version of a page when similar content has several accessible addresses.
HTTP status code
A numeric response that describes the result of a web request.
Redirect
A server or platform instruction that sends a request to another address.
404 page
A page shown when the requested resource cannot be found at that address.
Robots.txt
A text file that gives compliant crawlers guidance about which paths they may request.
Sitemap XML
A structured file listing public URLs that helps search engines discover site pages.
03 / 10

Interface & experience design

22 terms
User interface (UI)
The visible controls, text and layout through which a person uses a product.
User experience (UX)
The overall ease, clarity and quality of a person's interaction with a product.
Information architecture
The way content, pages and navigation are organised so people can find information.
Wireframe
A simplified layout plan showing structure before final visual styling.
Prototype
A model of an interface used to explore or test an interaction.
Design system
A maintained collection of design rules, reusable components and usage guidance.
Design token
A named value for colour, spacing, type or another shared design decision.
Component
A reusable interface element that performs a defined presentation or interaction role.
Typography
The choice and arrangement of typefaces, sizes, spacing and text hierarchy.
Visual hierarchy
The use of size, position, contrast and spacing to show relative importance.
Whitespace
The deliberate empty space that separates content and improves readability.
Grid layout
A layout system that aligns content in rows and columns.
Flexbox
A CSS layout model for arranging items along one dimension.
Contrast ratio
A numerical comparison of foreground and background luminance used to assess readability.
Colour palette
A selected group of colours used consistently across an interface or brand.
Affordance
A visual or behavioural clue suggesting how an interface element can be used.
Microinteraction
A small response to an action, such as a toggle changing state.
Interaction feedback
A message or visual change that tells a person what happened after an action.
Empty state
A screen shown when a list or feature has no content yet.
Error state
A view that explains a problem and helps a person recover.
Loading state
A temporary view that indicates a request or operation is still in progress.
Responsive breakpoint
A screen-width threshold where a layout changes to remain usable.
04 / 10

Software engineering & release

22 terms
Source code
Human-readable instructions that define how a software application behaves.
Repository
A managed collection of source files and their change history.
Git
A version-control system used to record and manage source-code changes.
Commit
A recorded set of repository changes with an identifying message and revision.
Branch
A separate line of development within a version-controlled repository.
Merge
The process of combining changes from different branches or development lines.
Pull request
A Git hosting workflow for proposing and reviewing changes before merging them.
Continuous integration (CI)
Automated checks that run when code changes are proposed or pushed.
Continuous deployment (CD)
An automated process that publishes validated code to a target environment.
Build
A process that prepares source files for a deployable application or website.
Release
A reviewed version made available to its intended users or environment.
Versioning
A system for identifying software revisions and communicating change over time.
Runtime
The environment and process in which a program executes.
Dependency
A library, package or service that software relies on to work.
Package manager
A tool for installing and maintaining software libraries and their versions.
Refactoring
Changing internal code structure while aiming to preserve its external behaviour.
Technical debt
Future maintenance cost created by shortcuts or incomplete engineering decisions.
Feature flag
A controlled setting that enables or disables a feature without replacing the whole application.
Environment variable
A configuration value supplied to an application by its runtime environment.
Staging environment
A separate environment used to review changes before production release.
Production environment
The live environment serving real users and operational data.
Rollback
The process of returning to a previously working software version.
05 / 10

Backend, data & APIs

22 terms
Frontend
The part of an application that runs in the user's browser or device.
Backend
The server-side logic and services that support an application.
Database
An organised system for storing, retrieving and managing structured or unstructured data.
Relational database
A database that stores structured data in related tables.
Table
A database structure containing rows of records with defined columns.
Row
A single record stored in a database table.
Column
A named field that defines one attribute in a database table.
Database schema
The structure that defines tables, types, relationships and database objects.
Structured Query Language (SQL)
A language used to create, read and manage data in relational databases.
PostgreSQL
An open-source relational database known for extensibility and standards-oriented SQL support.
CRUD
The four basic data operations: create, read, update and delete.
Database transaction
A group of database operations treated as one logical unit.
Database index
A structure that can help a database locate records more efficiently.
Database migration
A recorded change to database structure or configuration.
Query
A request for data or an instruction to operate on stored data.
Application programming interface (API)
A defined interface that allows software systems to communicate.
REST API
An API style that commonly uses HTTP methods and resource-oriented URLs.
Webhook
An HTTP message sent to another system when a specified event occurs.
Software development kit (SDK)
A collection of tools and code that helps developers use a platform or service.
JSON
A text format for representing structured data using objects, arrays and values.
CSV
A plain-text format for representing tabular data with separated values.
Object storage
A storage model for files such as images, documents and media assets.
06 / 10

Security, identity & privacy

22 terms
Authentication
The process of verifying who a user or service is.
Authorization
The process of deciding what an authenticated user or service may do.
Multi-factor authentication (MFA)
A login method that requires more than one independent proof of identity.
Session
A period in which a user remains authenticated to an application.
Access token
A credential presented to a service to authorise a request.
JSON Web Token (JWT)
A compact token format that can carry signed claims between systems.
OAuth 2.0
An authorisation framework that lets applications obtain limited access to another service.
OpenID Connect (OIDC)
An identity layer built on OAuth 2.0 for user sign-in.
Row-level security (RLS)
Database rules that limit which rows a user or role can access.
Least privilege
A security principle that grants only the permissions needed for a task.
Encryption at rest
Protection that encrypts stored data on disks or storage systems.
Encryption in transit
Protection for data while it travels between systems over a network.
Secret key
A confidential credential that must stay on trusted server-side systems.
Publishable API key
A public client key designed to identify an application without granting administrator authority.
Service-role key
A highly privileged backend credential that must never be exposed in browser code.
Content Security Policy (CSP)
A browser security policy that restricts where scripts, styles and connections may load.
Cross-origin resource sharing (CORS)
Browser rules that control whether a page can request resources from another origin.
Cross-site request forgery (CSRF)
An attack that attempts to make a browser perform an unwanted authenticated action.
Cross-site scripting (XSS)
An attack where untrusted content is executed as script in another user's browser.
SQL injection
An attack that manipulates database queries through unsafe handling of user input.
Audit log
A record of significant actions used to support investigation and accountability.
Data minimisation
Collecting and retaining only the personal information required for a stated purpose.
07 / 10

Commerce & business operations

22 terms
Product catalogue
An organised collection of products with descriptions, prices and relevant attributes.
Stock keeping unit (SKU)
An identifier used to distinguish a particular product or variant in inventory.
Inventory
The recorded quantity and status of goods available for sale or use.
Stock alert
A notice that inventory has reached a defined low or exception threshold.
Order
A recorded request to purchase specified goods or services.
Shopping cart
A temporary collection of items selected before a customer checks out.
Checkout
The process where a buyer confirms items, details and payment choices.
Payment gateway
A service that securely routes payment information to a payment processor.
Payment processor
A provider that handles authorisation and settlement of payment transactions.
Order fulfilment
The process of preparing, packing and completing an order for delivery or pickup.
Shipping method
A defined way goods are transported to a buyer.
Refund
Money returned to a buyer after an eligible transaction.
Tax calculation
The process of determining applicable taxes for a transaction or location.
Business-to-business (B2B)
Commercial activity where one business sells to another business.
Business-to-consumer (B2C)
Commercial activity where a business sells directly to individual consumers.
Wholesale
The sale of goods in quantities intended for resale or organisational use.
Distribution
The movement and supply of products from producers or suppliers to buyers.
Purchase order
A buyer-issued document specifying goods or services they intend to purchase.
Invoice
A commercial document requesting payment for supplied goods or services.
Quotation
A proposed price and scope for work or goods before an order is agreed.
Supplier
A person or organisation that provides products, materials or services.
Payment reconciliation
The process of matching recorded payments with invoices, orders and bank transactions.
08 / 10

Search, content & marketing

22 terms
Search engine optimisation (SEO)
Work that helps search engines understand pages and helps people discover relevant content.
On-page SEO
Improvements to page content, headings, titles and links that clarify relevance.
Technical SEO
Work on crawlability, indexing, site structure and technical search requirements.
Search intent
The purpose or question behind a person's search query.
Search engine results page (SERP)
The page a search engine displays in response to a query.
Crawling
The process by which a search engine visits pages and follows links.
Indexing
The process by which a search engine analyses and stores page information.
Meta description
A short page summary that may appear in search result snippets.
Title tag
The HTML title that identifies a page in browser tabs and search results.
Alternative text (alt text)
A text description of an image's purpose or meaningful visual content.
Structured data
Machine-readable page information that describes entities and content relationships.
Schema.org
A vocabulary used to describe entities and content for structured data.
Open Graph metadata
Tags that help social platforms display a page title, description and image.
Social preview image
An image selected to represent a page when it is shared online.
Organic traffic
Visits that arrive from unpaid search or other non-advertising discovery.
Paid campaign
A promotion where an organisation pays a platform to distribute content or adverts.
UTM parameters
URL tags used to identify the source and campaign of incoming visits.
Web analytics
Measurement of website visits, interactions and defined business outcomes.
Bounce rate
An analytics measure whose meaning depends on the event model and reporting platform.
Attribution
A method for assigning credit to marketing touchpoints that contributed to an outcome.
Editorial calendar
A plan for what content will be published and when.
Conversion copywriting
Writing that helps a reader understand an offer and take a relevant action.
09 / 10

Performance, testing & reliability

22 terms
Core Web Vitals
Google's group of user-centred metrics for loading, responsiveness and visual stability.
Largest Contentful Paint (LCP)
A metric that measures when the largest visible content element is rendered.
Interaction to Next Paint (INP)
A metric that assesses how quickly a page responds to user interactions.
Cumulative Layout Shift (CLS)
A metric that measures unexpected movement of page content while it loads.
First Contentful Paint (FCP)
The time until the browser renders the first piece of page content.
Time to First Byte (TTFB)
The time between a request being sent and the first response byte arriving.
Lazy loading
Deferring non-critical images or resources until they are closer to being needed.
Code splitting
Dividing code into smaller bundles so only required parts load initially.
Minification
Removing unnecessary characters from code without changing its intended behaviour.
Compression
Reducing the size of transferred resources using a supported encoding.
Browser cache
A local store that can reuse previously downloaded resources.
Content delivery network (CDN)
A distributed network that serves content from locations closer to visitors.
WebP
An image format that often provides smaller files than older web formats.
AVIF
A modern image format that can provide efficient compression for supported browsers.
Preload
A browser hint requesting an important resource early.
Preconnect
A browser hint that starts connection setup to an important external origin.
Responsive image
An image delivery approach that selects suitable dimensions for the display context.
Lighthouse
A tool for auditing aspects of web performance, accessibility, SEO and best practices.
Smoke test
A quick check that the most important functions work after a change.
Regression test
A test that checks whether existing behaviour still works after new changes.
Load testing
Testing how an application behaves under a defined amount of traffic or work.
Monitoring
Collecting information about system behaviour to detect problems and trends.
10 / 10

AI, automation & product delivery

22 terms
Artificial intelligence (AI)
A broad field of methods that enable machines to perform tasks associated with human intelligence.
Machine learning (ML)
Methods that allow a system to learn patterns from examples or data.
AI model
A trained computational system that produces outputs from inputs.
Model training
The process of adjusting model parameters using data and an optimisation method.
Inference
Using a trained model to generate a prediction or response.
Prompt
Instructions or context supplied to an AI system for a particular task.
Embedding
A numerical representation that places information in a vector space.
Vector search
Searching for items using similarity between numerical vector representations.
Retrieval-augmented generation (RAG)
A method that retrieves relevant information before asking a model to generate an answer.
Hallucination
An AI output that presents unsupported or incorrect information as though it were true.
AI agent
A system that uses a model and tools to pursue a defined task.
Automation
A process where software performs defined actions with reduced manual input.
Workflow automation
Connecting steps, decisions and systems so a recurring process can run consistently.
Trigger
An event that starts an automated workflow or action.
Queue
A structure that holds tasks until workers or services can process them.
Cron job
A scheduled task that runs at defined times or intervals.
Minimum viable product (MVP)
A focused initial product release designed to test a core value proposition.
Product roadmap
A planning view of product goals, priorities and intended development direction.
Backlog
A prioritised list of work items that may be considered for future delivery.
Sprint
A time-boxed period used by a team to plan and complete selected work.
Acceptance criteria
Conditions that must be met for a requirement or task to be considered complete.
Quality assurance (QA)
Activities that help verify a product meets its requirements and works reliably.
