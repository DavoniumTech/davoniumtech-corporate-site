This site is a Progressive Web App (PWA). When browser support and installation criteria allow, use the install button; otherwise follow the manual steps below.

▣
Installable website

Try the browser prompt

If your browser exposes a native install prompt, the button will call it and the browser will ask for confirmation.

If no native prompt is available, this area will show manual steps.

Installation is optional. It does not install an APK or guarantee every feature works offline.

Android

  1. Open this site in a supported browser over HTTPS.
  2. Use Install app if a native prompt appears and confirm.
  3. If it does not appear, open the browser menu and look for Install app or Add to Home screen.

iPhone and iPad

  1. Open the website in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen and confirm.

Desktop

In a compatible browser, look for an install icon in the address bar or an Install page as app item in the menu.

Offline use

The service worker caches selected pages and assets after an online visit. External links and online workflows still require a connection. Read the PWA guide and offline-first guide.
