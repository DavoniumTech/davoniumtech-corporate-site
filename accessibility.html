ACCESSIBILITY

Designed to be easier to use.

We want the Davonium Technologies website to remain understandable across devices, input methods and display preferences.

Our approach

We aim to use semantic HTML, clear heading order, readable type, visible keyboard focus, sufficient colour contrast, descriptive links and navigation that can be used on smaller screens.

Display preferences

The website provides light and dark themes and respects reduced-motion preferences for animations. We aim not to rely on colour alone to communicate important status.

Known limitations

As this refreshed website is new, it still needs real testing with keyboard navigation, screen readers, browser zoom and a range of mobile devices. We do not claim complete accessibility certification.

Share feedback

If you encounter an accessibility barrier, tell us which page you were using, what you were trying to do, your device/browser, and any workaround you found useful. Contact support@davoniumtech.com or the alternative general inbox.
