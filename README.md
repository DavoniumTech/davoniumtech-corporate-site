# Davonium Technologies — V55

Cinematic digital-product studio refresh.

- Global services across websites, web apps, Android/mobile apps, software systems and digital products.
- One shared V55 base stylesheet and one theme layer to avoid stacked legacy overrides.
- Deep indigo / slate night mode and porcelain light mode, with restrained multicolour glows and star details.
- Seven independent demo identities and seven showcase certificate PDFs.
- Compact DVNM Bot, explicit user-triggered welcome, and a guarded one-command Windows publisher.

## Local preview
Open `index.html` or serve the directory with any static HTTP server. For deployment, use `DEPLOY-V55-WINDOWS.cmd` and follow the interactive safety checks. The script requires Git for Windows and authenticated access to the Davonium Technologies repository.
